/ 04 — Process
How an engagement runs

Discover, model, ship, run. We don't theorize — we deploy.

01

Discover

Two weeks. We map every workflow that touches unstructured input — emails, forms, PDFs, calls — and score each on cost, frequency, and risk.

→ Heatmap
02

Model

We pick one or two workflows, model the ROI, design the agent's behaviour, and write the governance rules: who owns it, when humans intervene, how it fails safely.

→ Roadmap + RACI
03

Ship

4–8 weeks per workflow. Connect to existing systems, train the agent on your real data, run shadow mode, then go live with named human reviewers.

→ Working agent
04

Run

Monthly retainer. We monitor accuracy, retrain when models update, audit governance, and write you a one-page report on what the agent did and what it cost.

→ Ongoing ops
