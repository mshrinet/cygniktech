SYS // 02 — HITL FLOW
/ Process
4–8 weeks per workflow

Design → build → shadow → cutover.

01
Week 1–2

Design

Behavior spec, edge cases, escalation paths, governance rules. Who owns the output, when humans intervene, how it fails safely. Signed off before a line of integration code is written.

→ Behavior spec + RACI
02
Week 2–5

Build

Connect to source systems, train on your real data, wire the orchestration. We use proven model + framework combinations — not bleeding edge for its own sake.

→ Working agent in staging
03
Week 4–7

Shadow

The agent runs in parallel with humans. Every output is reviewed; every disagreement is logged and used to tune. We don't move to live until accuracy clears the threshold you set.

→ Calibrated confidence model
04
Week 6–8

Cutover

Phased rollout — confidence-gated auto-execute, human queue for the rest. Owner trained, dashboards live, runbook handed over. Optional handoff to S-04 retainer.

→ Live agent + handover doc
